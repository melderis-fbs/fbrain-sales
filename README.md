# Founders Sales OS

El sistema operativo comercial de Founders. Todavía no hay aplicación: hay un
análisis del estado actual y un plan.

**Empezá por [`docs/IMPLEMENTATION-PLAN.md`](docs/IMPLEMENTATION-PLAN.md).**

Lo que contesta, en orden:

1. Qué existe hoy y dónde (son cuatro aplicaciones, no una).
2. Qué deuda técnica arrastra cada una.
3. Qué pide el documento maestro contra lo que hay, módulo por módulo.
4. Arquitectura, modelo de datos, rutas, componentes, APIs y jobs propuestos.
5. El motor de scoring, el pipeline de IA y el motor de matching en detalle.
6. Qué datos históricos se pueden traer, cuáles no, y por qué.
7. Las fases, en orden de dependencia.
8. **Las catorce decisiones que faltan definir** (Parte 15). Cinco bloquean.

No hay código de la aplicación en este repositorio todavía, a propósito: el
prompt maestro pide analizar y proponer antes de programar.
